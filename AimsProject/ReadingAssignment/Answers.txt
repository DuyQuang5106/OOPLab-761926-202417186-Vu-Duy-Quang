1. If you create a constructor method to build a DVD by title then create a constructor method to build a DVD by category. Does JAVA allow you to do this? 
2.Question: Is JAVA a Pass by Value or a Pass by Reference programming language?
3.Question:  
● After the call of swap(jungleDVD, cinderellaDVD) why does the title of these two 
objects still remain? 
● After the call of changeTitle(jungleDVD, cinderellaDVD.getTitle()) why is 
the title of the JungleDVD changed? 


1. No, Java does not allow you to create two constructors like that if they only differ by parameter name but have the same type. If both constructors take a single String (one for title, one for category), Java will see them as the same signature and give an error. You need different parameter types or number of parameters.

2. Java is a pass by value programming language. Even when working with objects, Java passes a copy of the reference, not the actual object reference itself.

3. After calling swap(jungleDVD, cinderellaDVD), the titles remain the same because the method only swaps the copies of the references, not the original objects. So outside the method, nothing actually changes. 
After calling changeTitle(jungleDVD,cinderellaDVD.getTitle()), the title of jungleDVD changes because the method modifies the actual object that the reference points to. Even though the reference is passed by value, it still points to the same object, so changes to the object are visible outside the method.
